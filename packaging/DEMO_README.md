# RVC 声迹客户端 — 阶段性演示版

## 演示功能

| 功能 | 说明 |
|------|------|
| **制作歌曲** | 导入原唱 → MSST 分离 → RVC 变声 → 生成 cover.wav |
| **AI 唱歌** | 播放页选择歌曲 → 点击「AI 唱歌」试听成品 |
| **普通说话** | 麦克风原声直通（不变声），用于验证声卡路由 |
| **歌词** | 同名 LRC 随制作/copy 到输出目录，播放时高亮 |

> 本演示包**不包含** AI 跟唱实时变声联调、Studio One OSC、自动更新服务器。

## 环境要求

- Windows 10/11 64 位
- NVIDIA 显卡 + CUDA（推荐 12GB 显存；长歌曲自动分段推理）
- 已安装 **Voicemeeter**（普通说话 / 后续跟唱用）
- **FFmpeg** 已内置在 `tools\ffmpeg\`
- **Python + PyTorch** 已内置在 `python\`（完整演示包）
- **显卡版本**：发客户前确认选对包（见根目录 `GPU_VARIANT.txt`）
  - **cu118 包**：RTX 50 系及以前（GTX 10 系及以上）
  - **cu128 包**：RTX 50 系及以后

## 首次使用

1. 解压到任意目录（路径建议无中文、无空格）
2. 将 RVC 模型（`.pth` + 可选 `.index`）放入 `assets/weights` 与 `assets/indices`（完整包可能已含示例模型）
3. MSST 权重需在 `assets/pymss_weights`（完整包已含）
4. 双击 **`StartClient.bat`** 或 **`启动声迹客户端.bat`**
5. **设置** → 配置音频 IN/OUT → **RVC 高级设置** 选模型 → 保存

## AI 唱歌演示流程（推荐）

1. 打开 **制作歌曲** → 拖入一首原唱（mp3/wav）
2. 选模型 → **开始处理**（普通做歌约 2~5 分钟，视显卡与时长而定）
3. 完成后自动跳转 **播放** 页 → 点击 **AI 唱歌**
4. 向客户展示波形、歌词高亮与 AI 人声成品

## 常见问题

- **找不到模型**：设置 → RVC 高级设置 → 导入/选择 .pth
- **做歌失败找不到 ffmpeg**：确认包内存在 `tools\ffmpeg\ffmpeg.exe`（建议同时放 `ffprobe.exe`）
- **普通说话无声音**：设置里检查设备 index；Voicemeeter 路由见开发文档
- **做歌报 No module named torch**：未内置 python/ → 重新打包；或选错 cu118/cu128 版本
- **50 系显卡报错 / 无 GPU**：客户需 cu128 包，不能用 cu118 包
- **AI 唱歌不变声**：正常，播放的是预生成 cover；实时变声属于 AI 跟唱（后续版本）
